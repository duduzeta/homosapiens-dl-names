Homosapiens Download Names

Renomeia downloads com nomes que fazem sentido, usando o contexto da página e o LLM que você escolher (z.ai, OpenAI, Anthropic, Gemini, Ollama…).

Conexão

Trocar o provedor preenche a Base URL e o modelo sugerido; você pode editar os dois depois.
Fica salva só neste navegador (chrome.storage.local).
Raiz da API, sem /chat/completions. z.ai Coding Plan: https://api.z.ai/api/coding/paas/v4
Se o modelo não responder a tempo, o nome original é mantido. Máximo ~14s (limite do Chrome).
Se ativar, aumente o timeout para ~14 s. Só aparece para provedores que expõem esse controle.

Estilo dos nomes

Idioma, formato (Title Case, kebab-case…), o que incluir. A extensão do arquivo é sempre preservada.
